# AURIX Sprint 2

Interfaz de tienda AURIX construida con Next.js, React y Tailwind CSS.

## Entregables actuales

- Proyecto en React / Next.js.
- Estructura de carpetas organizada.
- Layout principal con Header y Footer.
- Navegación funcional por secciones.
- Página principal completa con diseño Tailwind.
- Catálogo de productos.
- Tarjetas de producto reutilizables.
- Vista de detalle por producto.
- Productos relacionados.
- Filtros visuales por categoría.
- Datos mock desde `data/products.json`.
- Secuencia de imágenes por scroll en `public/imagenes_scroll`.
- Estética blanco/negro inspirada en interfaces limpias tipo Antigravity.

## Estructura

```text
components/
data/
layouts/
pages/
styles/
public/imagenes_scroll/
```

## Ejecutar el proyecto

Instalar dependencias:

```bash
npm install
```

Iniciar entorno de desarrollo:

```bash
npm run dev
```

Abrir la URL que muestre Next.js, normalmente:

```text
http://localhost:3000
```
